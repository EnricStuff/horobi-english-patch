# horobi-english-patch

A Bouquet of Remembrance for a Decaying World — English Patch
滅び朽ちる世界に追憶の花束を (Horobi Kuchiru Sekai ni Tsuioku no Hanataba o) Original freeware visual novel by 郷愁花屋 (Kyoushuu Hanaya), 2010 · VNDB v12728

An unofficial, complete English fan translation. This patch contains no game data: you need the original Japanese game (ver. 1.00).

Download
Get the latest version from the ../../releases page.

Installation
Install the original game.
Open the game folder (the one with 滅び朽ちる世界に追憶の花束を.exe).
If there's already a patch.xp3 in it (the community bug-fix patch), rename it to patch.xp3.bak. Those bug fixes are already included in this patch.
Copy patch.xp3 and English Patch README.txt into the game folder.
Start the game as usual.
To uninstall, delete patch.xp3, and rename patch.xp3.bak back if you kept it.

If the game won't start or shows garbled text on a non-Japanese system, run it through Locale Emulator with a Japanese profile.

What's translated
Everything you read in the game:

The prologue, all eight stories, every Remembrance fragment and the epilogue.
The author's afterwords and the in-game dictionary.
Menus, dialogs, config, save names, tooltips and the music room.
The Bouquet Maker, the time-machine password replies, and every image with Japanese text (title logo, menus, captions).
Text is word-wrapped and paced for English. Character names are in Western order, and honorifics are rendered with natural English equivalents.

Reporting issues
Found a typo, an awkward line, or text that doesn't fit? Please open an issue and include:

the story and chapter
the English line (a screenshot is ideal)
what's wrong, and a suggested fix if you have one
